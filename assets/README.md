# Карта игры

Положи сюда файл карты и назови его `map.jpg` (или `map.png` —
тогда поменяй расширение в js/data.js, в переменной MAP_IMAGE_URL).

Чтобы обновить карту в будущем: просто замени этот файл в репозитории
(через "Add file → Upload files" на GitHub, или обычным `git add` /
`git commit` / `git push`) — сайт сам подхватит новую версию у всех
посетителей при следующей загрузке страницы, ничего больше делать
не нужно.
